# Release v1.1.1

Released: 2026-10-08.

## Fixes

- Prevented a task watchdog while entering, cancelling, or retrying SoftAP by
  suspending native Emote rendering while LVGL owns the display and avoiding
  redundant WLAN UI updates.
- Moved Factory Reset to an internal-memory task stack so NVS erase operations
  do not run from the PSRAM-backed LVGL worker stack.
- Suppressed INFO-level MCP initialization payloads that can contain
  server-issued tokens.

## Security

- Disabled the ESP-TLS insecure and skip-server-certificate-verification
  options.
- Kept the full ESP x509 certificate bundle enabled and verified HTTPS
  activation, MQTTS on port 8883, and OpenWeather HTTPS on hardware.
- Confirmed that a client without a certificate trust source fails closed
  instead of falling back to an insecure connection.

## Dependencies and build

- Added `dependencies.lock` to the repository so release builds use the exact
  dependency graph validated for this patch.
- Kept the four documented ESP-Brookesia component overrides because the
  corresponding Registry releases do not yet contain the local fixes.
- Kept `brookesia_service_helper` pinned to 0.8.4 because 0.8.5 requires a HAL
  header that is absent from the locked HAL package.
- Renamed the CMake project to `esp_chatbot` and added a pinned ESP-IDF 6.1
  firmware-build job for `esp_vocat_board_v1_0`.
- Removed stale upstream test and board configuration files.

## Documentation

- Corrected the v1.1.0 Weather import path to
  `/sdcard/config/weather-import.json` and documented its successful rename to
  `/sdcard/config/weather-imported.json`.

## Validation

- ESP-IDF 6.1 firmware build for `esp_vocat_board_v1_0` passed.
- Simulator regression suite passed: 23/23 tests.
- Visual parity, 74-file UI integrity, credential scanning, and lockfile
  stability passed.
- Upgrade from v1.1.0 without erasing flash retained Wi-Fi, Weather, display,
  audio, model, LittleFS, and animation data.
- Clean installation, first-boot SoftAP, activation, reboot persistence,
  Weather import, voice conversation, Goodbye/wake recovery, WLAN off/on,
  touch, display, microphone, speaker, brightness, volume, mute, and Factory
  Reset passed on hardware.
- Weather and SNTP timeout/retry fault injection completed without a watchdog,
  panic, reset, or retry storm.
- Equivalent v1.1.0 and v1.1.1 display diagnostics showed no observable QSPI
  regression. Runtime heap remained stable; v1.1.1 used approximately
  1.4-3.9 KiB more PSRAM with equivalent internal heap.
- A 61-minute hardware soak completed six Weather refreshes while XiaoZhi
  remained connected, with no reset, watchdog, or continuous heap loss.

## Known limitations

- `MBEDTLS_HAVE_TIME_DATE` remains disabled in this patch. Certificate chains
  and hostnames are verified, but certificate validity dates are not checked.
- The production service selected MQTTS on port 8883 during validation. MQTT
  transport remains server-selected; a server-provided TCP endpoint would not
  be encrypted. The unused WSS path was not dynamically exercised.
- The latest Weather forecast is retained during a same-runtime network outage
  but is not persisted across reboot. A cold boot without Weather connectivity
  displays `--` until a refresh succeeds.
- OTA, BLE, and camera support remain unavailable and are outside this patch.

## Flashing

The merged factory image contains the bootloader, partition table, speech
model, application, LittleFS, and animation partitions. Flash it at offset
`0x0`:

```sh
esptool.py --chip esp32s3 write_flash 0x0 esp_chatbot-v1.1.1-esp_vocat_board_v1_0-merged.bin
```

The merged raw image fills partition gaps and overwrites NVS. It therefore
removes saved Wi-Fi, activation, Weather, brightness, and volume settings.

For an upgrade from v1.1.0 that preserves NVS and the unchanged data
partitions, flash only the application at `0xb0000`:

```sh
esptool.py --chip esp32s3 write_flash 0xb0000 esp_chatbot-v1.1.1-esp_vocat_board_v1_0.bin
```

To refresh the application and all release data partitions without writing
NVS, use the separate images and offsets:

```sh
esptool.py --chip esp32s3 write_flash \
  0x10000 esp_chatbot-v1.1.1-esp_vocat_board_v1_0-srmodels.bin \
  0xb0000 esp_chatbot-v1.1.1-esp_vocat_board_v1_0.bin \
  0xc2d000 esp_chatbot-v1.1.1-esp_vocat_board_v1_0-littlefs.bin \
  0xcaa000 esp_chatbot-v1.1.1-esp_vocat_board_v1_0-anim-icon.bin
```

Verify downloaded files against
`esp_chatbot-v1.1.1-esp_vocat_board_v1_0-SHA256SUMS.txt` before flashing.
