# Release v1.1.0 (Draft)

Status: release candidate validated on ESP VoCat v1.0.

## Highlights

- Added the project-owned eye emote pack and unified XiaoZhi UI states.
- Added SoftAP provisioning, saved-network recovery, and improved WLAN state handling.
- Added live weather, SNTP clock data, and SD-card weather configuration.
- Added hardware self-test for the ESP VoCat peripherals.
- Improved display switching and memory use for the QSPI screen.
- Added a hardware boot splash and a safe persisted-backlight startup sequence.
- Simplified the launcher to keep Clock and Settings in stable positions.

## Validation

- ESP-IDF v6.1 build and flash for `esp_vocat_board_v1_0` passed.
- Hardware smoke test on ESP VoCat v1.0 passed.
- Simulator regression suite passed: 23/23 tests.
- Visual parity, 74-file UI integrity, and credential scans passed.

## Notes

- Camera, BLE, and OTA are not included in this release.
- Weather credentials are imported from `/sdcard/config/weather.json` and are
  not stored in the repository.
