# Release v1.0.0

## Scope

- Exact Speaker UI port for ESP VoCat v1.0 and the PC simulator.
- Launcher, Quick Settings, Clock, Settings, WLAN and keyboard.
- Functional Wi-Fi, brightness, volume, Factory Reset, About and Developer Mode.
- Native Emote integration and the XiaoZhi agent.
- BQ27220 battery monitoring, GPIO7 touch input, head LED and BMI270 motion
  detection.
- PC simulator with deterministic stubs, opt-in native backends and self-tests.

## Validation

- ESP-IDF v6.1 build for `esp_vocat_board_v1_0`.
- Hardware smoke test on ESP VoCat v1.0.
- Simulator regression suite: 22/22 CTest tests passed.
- UI visual parity and source-integrity checks passed.

## Notes

BMI270 motion events use the `confused` (`@@`) emote provided by the current
Emote engine instead of the legacy `dizzy` AAF asset from the older
`esp_speaker` firmware.
