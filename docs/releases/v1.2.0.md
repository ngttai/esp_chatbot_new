# v1.2.0

## New

- Power management with automatic dimming, coordinated LCD sleep and safe wake.
- Lift to wake using the IMU, with a persistent setting.
- Updated status LED behavior for power and Wi-Fi states.

## Fixes

- Improved Quick Settings tap/hold gestures and Wi-Fi status display.
- Persisted Wi-Fi on/off and corrected startup/reconnect feedback.
- Reset UI scroll positions when returning Home.
- Fixed stale XiaoZhi status/emote feedback after disabling Wi-Fi.

## Installation

Download the ZIP for your board. It includes a merged factory image, individual
flash images, flashing instructions and SHA-256 checksums.
Factory flashing overwrites settings; use the app-only update to retain them
when upgrading from v1.1.1 on the same board and partition layout.

LCD sleep does not put the ESP32 into light/deep sleep. Third-party asset
attribution and licensing status are listed in `THIRD_PARTY_NOTICES.md`.
